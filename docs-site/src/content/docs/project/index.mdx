  - q: "How can I contribute to Shadow?"
    a: "Open an issue or a pull request on GitHub. Code, detectors, translations, docs and benchmark data are welcome; for large changes, open an issue first."
  - q: "Will there be a hosted Shadow service?"
    a: "No. Shadow is local by design, and a hosted service is not planned."
